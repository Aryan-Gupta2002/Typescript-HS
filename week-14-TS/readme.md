# TypeScript Practice

This repository contains my TypeScript learning and practice programs.

## Topics Covered

- Variables and data types
- Functions
- Type annotations
- Arrow functions
- Callbacks
- `setTimeout`
- Basic asynchronous programming
- TypeScript compilation

## Setup

Install dependencies:

```bash
npm install
```

## Compile TypeScript

```bash
npx tsc
```

or

```bash
npx tsc -b
```

## Run

```bash
node index.js
```

## Purpose

This project is used to learn and experiment with TypeScript concepts and understand how TypeScript code is compiled and executed.
